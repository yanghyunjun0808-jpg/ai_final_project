제출할 때 저장소에 있어야 하는 것
──────────────────────────────────────────────────────────
  main.py            고친 프로그램
  config.py          내가 고른 도메인 (한 줄만 바꾸면 됩니다)
  data/○○○.csv       내가 쓴 데이터
                     ★ 이것을 커밋하지 않으면 남이 내려받아도 못 돌립니다
  test_project.py    내가 만든 테스트          ← 없습니다. 14주차에 만듭니다
  README.md          채워 넣은 것              ← 뼈대가 들어 있습니다
  prompts.md         AI 에게 무엇을 어떻게 시켰는가   ← 양식이 들어 있습니다
  reflection.md      무엇이 막혔고 어떻게 풀었는가   ← 양식이 들어 있습니다

  README.md · prompts.md · reflection.md 는 빈칸만 채우면 됩니다.
  새로 만들지 말고 들어 있는 파일을 그대로 여세요.
  VS Code 에서 Ctrl + Shift + V 를 누르면 다 썼을 때 어떻게 보이는지 미리 볼 수 있습니다.

커밋 네 구간 (순서를 지키세요)
──────────────────────────────────────────────────────────
  1) fix:       공통 버그를 먼저, 그다음 내 데이터에서만 터지는 것 (두 번에 나눠서)
  2) test:      pytest 로 확인하는 코드
  3) refactor:  동작은 그대로 두고 구조만 정리
  4) feat:      기능 하나 추가

  구간이 끝날 때마다 prompts.md 의 해당 칸을 채워 두세요.
  나중에 한꺼번에 쓰려고 하면 무엇을 시켰는지 기억나지 않습니다.

★ 푸시하지 않은 커밋은 제출되지 않은 것입니다.  git push 까지 하세요.
