# 가계부 항목별 지출 분석기

## What — 무엇인가

가계부 CSV를 읽어 지출을 항목별로 합산하고 건수와 최댓값, 전체 평균을 보여 주는 프로그램입니다.

## Why — 어떤 문제를 푸는가

지출 내역이 많으면 어떤 항목에 돈을 많이 썼는지 한눈에 파악하기 어렵습니다. 이 프로그램은 CSV를 자동으로 분류별 요약으로 바꿔 지출을 살펴보도록 돕습니다.

## How — 어떻게 쓰나

프로젝트 폴더에서 실행합니다. 별도 패키지를 설치하지 않아도 됩니다.

```bash
python3 main.py
```

Windows에서 `python3` 명령이 동작하지 않으면 다음을 실행하세요.

```bash
python main.py
```

다른 데이터를 분석하려면 [config.py](C:/Users/USER/Downloads/Koreatech_AIPrograming_2026100003/week13/ai_final_project/config.py) 맨 위의 `배달주문` 값 오른쪽을 `가계부`, `운동기록`, `수면기록`, `공부시간`, `배달주문`, `소비기록` 중 하나로 바꾸세요. 프로젝트 폴더에서 실행해야 `data/` 경로를 찾을 수 있습니다.

## 데이터

| 항목 | 내용 |
|---|---|
| 파일 | `data/가계부.csv` |
| 행 수 | 원본 104행 → 분석 100행 |
| 열 | 날짜 · 항목 · 금액 |
| 버려지는 행 | 4행. 금액이 비어 있어 제외됩니다. |

## 내가 정한 처리 규칙 (= 복원한 명세)

1. 금액이 비어 있거나 공백뿐인 행은 분석에서 제외합니다.
2. 금액의 쉼표를 제거한 뒤 정수로 읽습니다. 정수로 바꿀 수 없는 값은 제외합니다.
3. 금액은 0원 이상 100,000원 이하일 때 유효합니다. 이 범위를 벗어난 행은 제외합니다.
4. 유효한 행은 항목별 합계·건수·최댓값을 계산하고, 전체 평균은 유효한 행의 금액으로 계산합니다. 날짜는 현재 분석에 사용하지 않습니다.

## When — 지금 어떤 상태인가

가계부 CSV를 읽어 유효하지 않은 금액을 제외하고 항목별 합계·건수·최댓값과 전체 평균을 출력합니다. 날짜별 검색이나 기간 비교 기능은 아직 없습니다.
